ExcelやWordの表をMarkdownに変換する方法

「Excelで作った表をREADMEやドキュメントに載せたい」「スプレッドシートの表をそのまま貼ったらぐちゃぐちゃになった」— Excel・Word・Googleスプレッドシートの表は、コピペしただけではMarkdown（マークダウン）の表になりません。このページでは、表をMarkdownテーブルに変換する4つの方法と、変換後に崩れないためのチェックポイントをまとめました。変換結果は無料のMarkdownビューアーに貼り付ければ、その場で確認できます。

なぜコピペだけでは表にならないのか

Excelやスプレッドシートで表をコピーすると、クリップボードにはタブ区切りのテキスト（TSV）として格納されます。これをテキストエディタやMarkdownファイルに貼り付けると、次のような「タブで区切られただけの文字列」になります。

Excelからそのまま貼り付けた状態
商品	価格	在庫
りんご	120	32
みかん	80	120
Markdownとして必要な形
| 商品 | 価格 | 在庫 |
| --- | --- | --- |
| りんご | 120 | 32 |
| みかん | 80 | 120 |

Markdownの表は |（パイプ）でセルを区切り、2行目に --- の区切り行を置く形式です（詳細は表の書き方ガイド参照）。つまり「タブ区切り → パイプ区切り」への変換が必要になります。

例外：NotionやGitHubのIssueコメント欄など、一部のアプリはExcelからの貼り付けを自動で表に変換してくれます。貼り付け先がMarkdownファイルやテキストエリアの場合に、この変換作業が必要です。

方法1: AIチャット（ChatGPT・Claude等）に変換してもらう

現在もっとも手軽なのがこの方法です。Excelの表をコピーして、AIチャットに貼り付け、こう頼むだけです。

プロンプト例
以下の表をMarkdownのテーブルに変換してください。

商品	価格	在庫
りんご	120	32
みかん	80	120
ポイント
  • 数値列の右寄せ、列の並べ替え、単位の追加なども同時に頼める
  • 数百行の大きな表は分割して依頼する
  • 機密データはAIに送る前に社内ルールを確認

AIの回答はMarkdown形式で返ってくるので、そのままコピーして使えます。変換結果が正しく表になっているかは、Markdownビューアーに貼り付ければ一目で確認できます。

方法2: オンライン変換ツールを使う

「Markdown table generator」「TSV to Markdown」などで検索すると、Excelからの貼り付けをMarkdownテーブルに変換してくれる無料のWebツールが多数見つかります。使い方はどれもほぼ共通です。

  1. Excel・スプレッドシートで表の範囲をコピーする
  2. 変換ツールの入力欄に貼り付ける（自動でセルに展開される）
  3. 生成されたMarkdownをコピーする
ツールによっては列の寄せ（:--- / :---: / ---:）の指定や、テキストの整列（パイプ位置を揃える整形）もできます。業務データを外部ツールに貼る場合は、データの取り扱いに注意してください。

方法3: VSCodeの拡張機能で変換する

開発中に頻繁に変換するなら、VSCodeの拡張機能が便利です。定番は「Excel to Markdown table」という拡張機能で、Excelからコピーした内容を Shift+Alt+V（Macは Shift+Option+V）で貼り付けると、その場でMarkdownテーブルに変換されます。

また「Markdown All in One」などの拡張機能を入れておくと、変換後の表の整形（列幅を揃える）やプレビューもエディタ内で完結します。VSCodeでのプレビュー方法はVSCodeでMarkdownをプレビューする方法で詳しく解説しています。

方法4: 手動で書き直す（小さい表向け）

3列×3行程度の小さな表なら、手で書いた方が早いこともあります。コツは最初に区切り行のテンプレートを書いてしまうことです。

テンプレート（列数分の --- を先に用意）
|  |  |  |
| --- | --- | --- |
|  |  |  |
ポイント

枠を先に作ってからセルを埋めると、列数のズレ（崩れの最大原因）を防げます。パイプの位置は揃っていなくても正しく表示されます。

変換後に崩れないためのチェックポイント

チェック項目問題が起きる例対処法
セル内の |「A|B」という値があると列がずれる\| にエスケープする
セル内の改行Excelのセル内改行（Alt+Enter）が行を分断する<br> タグに置き換える
セル結合結合セルが空セルの羅列になる変換前に結合を解除して各セルに値を入れる
空セル列数が合わず崩れる空でも | | とセルの枠は残す
先頭・末尾の空白見た目は問題ないが差分管理でノイズに整形機能のあるツールで揃える

崩れの原因と直し方の詳細はMarkdownの表（テーブル）の書き方にまとめてあります。セル結合の代替表現もそちらで解説しています。

よくある質問

逆に、Markdownの表をExcelに戻せますか？

Markdownの表をコピーしてExcelに貼ると1列に入ってしまいます。「区切り位置」機能で | を区切り文字に指定して分割するか、AIチャットに「この表をタブ区切りにして」と頼むのが手軽です。

Googleスプレッドシートでも同じ方法が使えますか？

はい。スプレッドシートのコピーも同じタブ区切り形式なので、このページの4つの方法がすべてそのまま使えます。

Wordの表はどうやって変換しますか？

Wordの表はいったんExcelに貼り付けてからコピーすると、確実にタブ区切りになります。またはWordの表を直接AIチャットに貼り付けて変換を頼んでも、ほとんどの場合正しく認識されます。

数字の桁区切りカンマ（1,200など）はそのままで大丈夫？

はい、Markdownの表ではカンマは特別な意味を持たないのでそのまま使えます。CSV経由で変換する場合のみ、カンマが区切り文字と衝突するため注意が必要です。
