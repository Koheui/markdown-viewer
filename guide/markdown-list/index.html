Markdownの箇条書き・番号付きリストの書き方

Markdown（マークダウン）のリストは - や 1. を行頭に付けるだけ — のはずが、「箇条書きにならない」「ネストが崩れる」「番号がずれる」というつまずきが意外と多い記法です。このページでは、箇条書き・番号付きリスト・チェックボックスの書き方と、崩れる原因の直し方をまとめました。動作は無料のMarkdownビューアーでその場で確認できます。

箇条書き（順序なしリスト）の基本

行頭に -（ハイフン）を書き、半角スペースを1つあけてから項目を書きます。* や + でも同じ結果になりますが、1つの文書内では記号を統一しましょう。

書き方
- りんご
- みかん
- ぶどう
表示結果
  • りんご
  • みかん
  • ぶどう
最重要ポイント：-りんご のようにスペースを省くと、リストとして認識されずそのまま表示されます。「箇条書きにならない」原因の大半はこのスペース忘れです。

番号付きリスト（順序付きリスト）の基本

行頭に 1. のように「数字＋ピリオド＋半角スペース」を書きます。

書き方
1. 材料を切る
2. 炒める
3. 味付けする
表示結果
  1. 材料を切る
  2. 炒める
  3. 味付けする

実は、書く数字はすべて 1. でも自動的に連番になります。後から項目を追加・並べ替えしても番号を書き直さなくて済むため、あえて全行 1. で書く流儀もあります。

書き方（全部 1. でOK）
1. 材料を切る
1. 炒める
1. 味付けする
表示結果（自動で連番になる）
  1. 材料を切る
  2. 炒める
  3. 味付けする

ネスト（入れ子）の書き方とインデント幅

子項目を作るには、行頭を半角スペース4つ（またはタブ1つ）で字下げします。

書き方（␣␣␣␣は半角スペース4つ）
- 果物
    - りんご
    - みかん
- 野菜
    - にんじん
表示結果
  • 果物
    • りんご
    • みかん
  • 野菜
    • にんじん
「スペース2つ」と「4つ」どっち？：GitHubやQiitaなど多くのサービスは2つでも動きますが、元祖Markdownや一部のパーサーは4つ（またはタブ）を要求します。4スペースに統一しておけばどの環境でも崩れません。番号付きリストの下にネストする場合は、親の「1. 」の文字幅に合わせて字下げが必要なため、なおさら4スペース以上が安全です。

チェックボックス（タスクリスト）の書き方

箇条書きの記号の後に [ ]（未完了）または [x]（完了）を付けると、チェックボックス付きのタスクリストになります。GitHubのIssueやNotionのToDo管理でおなじみの記法です。

書き方
- [x] 原稿を書く
- [x] レビューを依頼する
- [ ] 公開する
表示結果
  • 原稿を書く
  • レビューを依頼する
  • 公開する
チェックボックスはGitHub Flavored Markdown（GFM）の拡張記法です。未完了側の [ ] の中には半角スペースが1つ必要で、[] と詰めたり全角スペースを入れたりすると認識されません。

リストが崩れる・反映されない原因と対処法

症状原因対処法
箇条書きにならず「- 項目」のまま表示される記号の後の半角スペース忘れ／全角スペースを使っている- （記号＋半角スペース）に修正
文章の直後のリストが認識されない段落とリストの間に空行がない文章とリストの間に空行を1行入れる
ネストが反映されず同じ階層になる字下げが足りない（スペース1〜3つ）半角スペース4つで字下げする
番号が1から振り直されるリストの途中に空行や別の要素が挟まりリストが分断された項目間の空行を消す。項目内で改行したいときは行末スペース2つか<br>
リストの中に書いたコードや文章がずれる継続行の字下げ不足リスト項目の続きは4スペース字下げして書く

リスト項目の中での改行については改行できない・されない時の対処法で詳しく解説しています。

リストの見た目（行間・記号）を整えたいとき

「行間が詰まりすぎて読みにくい」「点（・）の色を変えたい」といった見た目の調整は、Markdown記法ではなく表示側のCSSの役割です。ブログに貼るときは、li の margin や line-height を調整すると読みやすくなります。

Markdown Viewerでは、本文の行間・余白をスライダーで調整しながらプレビューし、調整結果をそのままCSSとしてコピーできます。はてなブログやWordPressのデザインCSSに貼り付ければ、記事全体のリストの読みやすさを一括で整えられます。

リストの挙動、その場で確認しませんか？
スペースの数やネストの深さを変えると表示がどう変わるか、貼り付けるだけで試せます。

よくある質問

リストの項目の中に複数の段落を書きたい

項目の続きの段落を、空行を挟んだうえで半角スペース4つで字下げして書きます。字下げを忘れると、リストが終了して通常の段落になってしまいます。

番号を「途中から」始めたい（例：4から）

最初の項目に 4. と書けば、多くのパーサーで4から始まります。ただし途中の飛び番（1, 2, 5…）は連番に振り直されるため表現できません。

箇条書きの記号を「・」ではなく数字なし文字にしたい

記号の種類（●・○・■など）はCSSの list-style-type で変更します。Markdown記法自体には記号を選ぶ機能はありません。

リストと表を組み合わせられますか？

表のセル内でリスト記法は使えません。セル内で項目を分けたいときは <br> で改行して「・」を直接書くのが実用的です。詳しくは表（テーブル）の書き方をご覧ください。
