Markdown記法一覧【チートシート】
書き方を表示例つきで解説

Markdown（マークダウン）は、# や ** などの記号を使って、テキストだけで見出しや表・リンクを表現できる軽量マークアップ言語です。このページでは、よく使うMarkdownの書き方を「入力例」と「表示結果」のセットで一覧にまとめました。書き方を試したいときは、インストール不要の無料Markdownビューアーにコピペすれば、その場でプレビューできます。

見出しの書き方

行頭に # を付けると見出しになります。# の数が多いほど階層が深く（文字が小さく）なり、# 1個の見出し1（H1）から # 6個の見出し6（H6）まで使えます。# のあとには半角スペースが必要です。

書き方
# 見出し1
## 見出し2
### 見出し3
表示結果

見出し1

見出し2

見出し3

ブログ記事では、記事タイトルがH1になるため、本文中の見出しは ##（H2）から使うのが一般的です。

改行の書き方

Markdownでは、単純にEnterで改行しただけでは表示上は改行されません。改行するには次の2つの方法があります。

  • 行末に半角スペースを2つ入れて改行する（同じ段落内での改行）
  • 空行を1行挟む（新しい段落として分ける）
書き方
1行目（行末にスペース2つ）␣␣
2行目

空行を挟むと新しい段落
表示結果

1行目（行末にスペース2つ）
2行目

空行を挟むと新しい段落

␣ は半角スペースを表しています。ツールによっては <br> タグでの改行にも対応しています。

太字・斜体・打ち消し線

文字を *（アスタリスク）や ~（チルダ）で囲むと、文字を強調できます。

書き方
**太字**
*斜体*
***太字かつ斜体***
~~打ち消し線~~
表示結果

太字

斜体

太字かつ斜体

打ち消し線

リスト（箇条書き・番号付き・チェックリスト）

行頭に - を付けると箇条書きリスト、1. のように数字を付けると番号付きリストになります。行頭を半角スペース4つ（またはタブ）で字下げすると、入れ子（ネスト）にできます。

書き方
- 項目A
- 項目B
    - 項目B-1

1. 手順1
2. 手順2

- [x] 完了したタスク
- [ ] 未完了のタスク
表示結果
  • 項目A
  • 項目B
    • 項目B-1
  1. 手順1
  2. 手順2
  • 完了したタスク
  • 未完了のタスク

表（テーブル）の書き方

表は |（パイプ）で列を区切り、2行目に --- を並べたヘッダー区切り行を書きます。区切り行の : の位置で、列の文字寄せ（左寄せ・中央寄せ・右寄せ）を指定できます。

書き方
| 商品名 | 価格 | 在庫 |
| :--- | :---: | ---: |
| りんご | 150円 | 20 |
| バナナ | 100円 | 8 |
表示結果
商品名価格在庫
りんご150円20
バナナ100円8
:--- は左寄せ、:---: は中央寄せ、---: は右寄せです。表の書き方はズレやすいので、Markdownビューアーでプレビューしながら書くのがおすすめです。

リンクの書き方

リンクは [表示テキスト](URL) の形式で書きます。URLをそのまま貼るだけでリンクになるツールもあります。

書き方
[Markdown Viewer](https://markdown-viewer.net/)

タイトル付きリンク:
[公式サイト](https://markdown-viewer.net/ "Markdown Viewer")
表示結果

Markdown Viewer

タイトル付きリンク:
公式サイト

画像の挿入

画像はリンクの書き方の先頭に ! を付けた ![代替テキスト](画像URL) の形式で挿入します。代替テキスト（alt属性）は、画像が表示できないときや音声読み上げで使われる説明文です。

書き方
![サイトのロゴ](/favicon.svg)
表示結果

コードの書き方（インライン・コードブロック）

文章中の短いコードは `（バッククォート）1つで囲みます。複数行のコードは ```（バッククォート3つ）で囲んだ「コードブロック」にします。``` の直後に言語名（js、python など）を書くと、対応ツールではシンタックスハイライトが付きます。

書き方
インラインコードは `const x = 1;` のように書く

```js
function hello() {
  console.log("Hello, Markdown!");
}
```
表示結果

function hello() {
  console.log("Hello, Markdown!");

引用の書き方

行頭に > を付けると引用になります。>> と重ねると、引用の中の引用（ネスト）を表現できます。

書き方
> これは引用文です。
>> 引用の中の引用も書けます。
表示結果
これは引用文です。
引用の中の引用も書けます。

水平線（区切り線）

ハイフン3つ以上（---）だけの行を書くと、水平線（区切り線）になります。*** や ___ でも同じです。前後に空行を入れると確実です。

書き方
前の段落

---

次の段落
表示結果

前の段落

次の段落

よくある質問

MarkdownとHTMLの違いは？

Markdownは「書きやすさ」を重視した記法で、最終的にはHTMLに変換されて表示されます。HTMLより記号が少なくシンプルに書けるのが特長です。逆に、細かいデザイン指定はHTML/CSSの方が得意なので、Markdownで書いてHTMLに変換し、CSSで装飾する使い方が一般的です。

Markdownはどこで使えますか？

GitHub、Notion、Slack、Qiita、Zenn、はてなブログ、WordPress（プラグインまたはブロックエディタ）、VS Codeなど、多くのサービス・ツールが対応しています。ただし、対応している記法の範囲はサービスごとに少しずつ異なります。

書いたMarkdownをブログ用のHTMLに変換したい

Markdown ViewerにMarkdownを貼り付けると、整形済みのHTMLとCSSをワンクリックでコピーできます。はてなブログやWordPressの記事にそのまま利用できます。
